# Temporule（拾律）设计规范 v2 —— Raycast 布局语言

> 视觉设计唯一契约。v1 的 token 体系继续有效（色彩/圆角/字体/动效不变），
> v2 变更的是**布局语言与信息层级**：从「网页管理后台」范式改为「命令面板/紧凑行列表」范式。
> 变更本文件 = 变更契约。

## 布局语言（v2 核心变更）

### 禁止（v1 遗留的后台风元素）
- 数据表格 + 操作列（编辑/删除按钮横排占位）
- 大标题 + 大块空白的「页面」感
- 常驻显眼的编辑/删除按钮

### 行列表范式（核心组件 Row）
每条提醒 = 一行，高度 ~44px：
```
●  标题（13/500 text）                    [switch]
   摘要（11/400 text-dim，一行省略）
```
- 左：状态点（enabled=--success / disabled=--text-dim，6px 圆）
- 中：标题 + 灰色摘要两行堆叠
- 右：switch
- hover：整行提亮 `--surface-hover`，行尾淡入 编辑(✎)/删除(🗑) 图标按钮（图标 16px，text-dim，hover 变 text）
- 选中/焦点行：左侧 2px accent 竖条

### 仪表盘（440×560）
```
拾律 ●运行中                      ← 13/600 标题 + 状态点（顶部标题区，可拖动，✕）
─────────────────────────────
[Row] [Row] [Row] ...            ← 行列表，行高 44，分割线 1px --border
─────────────────────────────
[+ 新增]              [主窗口 ↗]   ← 底部 toolbar，高 44，ghost 按钮
```
- 无大标题、无卡片堆叠；列表区滚动
- toolbar 按钮：ghost 风（透明底、hover surface-raised）

### 主窗口（860×620）
```
提醒 | 历史 | 设置                ← Tab，当前项 text + 底部 2px accent 指示条，其余 text-dim
─────────────────────────────
[Row] [Row] [Row] ...            ← 提醒页：同仪表盘 Row，无表格
时间线：日期分组头(11/600 text-dim) + 行   ← 历史页：时间线，非表格
分组：开机自启 / 声音 / 隐私        ← 设置页：分组行，非堆叠
─────────────────────────────
```
- 无「+ 新增」大按钮：右上角 toolbar ghost 按钮「+ 新增」
- 历史行：时间(tabular-nums, text-dim) + 状态点 + 标题，一行
- 设置：分组标题(11/600 text-dim 大写间距) + 行式开关

### 弹窗（360×140）
```
● 每分钟一次            37s ✕    ← 单行：状态点+标题(13/500) + 倒计时(tabular, text-dim) + ✕
  备注一行省略（如有）
─────────────────────────────
[完成]                [稍后]     ← 主按钮 accent 右置、稍后 ghost；整行高 40
```
- 标题区可拖动；不抢焦点不变

### 表单（新增/编辑）
- 两列 grid 保留，但字段标签改 11/600 text-dim 置于输入框上方（原生 label 风格，非行内）
- 分组：「重复」「排程」「触达」用 11/600 text-dim 小节标题分隔（非边框盒子）

## 字体阶梯（v2 微调）

| 角色 | 规格 |
|---|---|
| 窗口标题（自绘标题区） | 13 / 600 |
| 行标题 / Tab 当前项 | 13 / 500 |
| 正文 / 按钮 | 13 / 400 |
| 摘要 / 辅助 / 分组标题 | 11 / 400（分组标题 600 + letter-spacing 0.5px） |
| 数字（倒计时/时刻） | tabular-nums |

## 色彩（v1 不变，新增 token）

| Token | 值 | 用途 |
|---|---|---|
| `--surface-hover` | `rgba(255,255,255,0.04)` | 行 hover |
| `--toolbar` | `rgba(255,255,255,0.02)` | 底部 toolbar 背景 |

其余 token（surface/surface-raised/border/text/text-dim/accent/success/warning/danger）沿用 v1。

## v3 —— 窗口 chrome 统一 + 主窗口侧栏骨架

### 窗口 chrome（根治割裂）

- 主窗口用 **Overlay 透明标题栏**（`titleBarStyle: Overlay` + 窗口 `transparent`）：红绿灯浮在深色内容上方，标题栏与内容区同为 `--surface`，零割裂
- 内容区顶部留 28px 红绿灯避让（padding-top），该条 `-webkit-app-region: drag` 可拖动
- 仪表盘/弹窗维持无标题栏自绘，不作改动

### 主窗口骨架：左侧边栏

```
┌──────────┬──────────────────────────────┐
│          │  提醒                    +新增 │
│          │ ──────────────────────────── │
│ ● 提醒    │  [Row] [Row] [Row] ...        │
│ ○ 历史    │                               │
│ ○ 设置    │                               │
│          │                               │
│ ───────  │                               │
│ ▣ 拾律   │                               │
│   v0.1.0 │                               │
└──────────┴──────────────────────────────┘
```

- 侧栏宽 180、独立背景（比内容区深一档：`--surface-side: #1a1a1d` 新 token），与内容区 1px `--border` 分隔
- **顶部留空**：Overlay 红绿灯占位（padding-top 28px），不放标题
- **底部品牌区**（`margin-top: auto` 贴底，上方 1px `--border` 分隔线，padding 12）：
  - 32×32 应用 logo（圆角 8，`--surface-raised` 衬底）
  - 「拾律」13/600 一行；版本号 11/400 text-dim（来自后端 `app_info` 命令）
  - 品牌区整块可点 = 「关于拾律」入口（hover 提亮 --surface-hover，圆角 6）
- 导航项：28px 高行、圆角 6、激活态 = `--surface-hover` 底 + `--accent` 文字/图标；图标 16px（提醒=铃铛、历史=时钟、设置=齿轮，单色 SVG currentColor）
- 内容区标题 15/600 置顶 + 右上 ghost「+ 新增」（仅提醒页）
- 侧栏导航改 pane 切换（pane 切换机制不变），顶部 Tab 条删除
- 空态（无提醒/无历史）：内容区中央放 13px text-dim 提示语（如「还没有提醒，点右上角新增」），不再是大片空白

### 关于面板

- 点品牌区 → 应用内轻量对话框（复用 dialog 样式语言），内容：64×64 logo、「拾律」15/600、「版本 0.1.0」11/400 text-dim、一行 12px「MIT License · 开源项目」、GitHub 仓库链接（accent 色，点击经后端命令用系统浏览器打开）
- 对话框宽度 ~320，居中，dark surface-raised，关闭按钮 ✕

### 质感细节（补齐）

- 焦点环：交互控件 focus-visible 时 2px `--accent` 外环（offset 2px）
- 滚动条：WebKit 细滚动条（8px、thumb `--border` 圆角、hover 提亮）——仪表盘列表与主窗口历史滚动区
- 选中行：行列表键盘/点选态 = `--surface-hover`（已有）+ 左侧 2px accent（已有）

### 表单（v4 重构：垂直单列节奏）

```
新增提醒                                    ✕
标题
[____________________________]
备注（可空）
[____________________________]

重复
[ 每天 | 每周 ]                        ← segmented
│ ▌一 二 三 四 五 六 日                 ← 每周才出现：缩进子配置 + 2px accent 竖线

排程
[ 每隔 | 固定时刻 ]                    ← segmented
│ ▌每隔 [2] [小时]  开始 [09:00]  结束 [18:00]
│ ▌固定时刻 [9:00,14:30]

触达
[ 系统通知 | 弹窗 ]                     ← segmented
│ ▌☑ 声音
│ ▌[ 自动消失 [30] 秒 | 强制处理 ]

▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔
[取消]                       [保存]
```

- **单列**：每字段 = 标签（11/600 text-dim 置顶）+ 控件 + 错误行；行间 12px，分组间 16px
- **Segmented**：容器 1px border + 圆角 6，内按钮等分；选中 = `--surface-raised` 底 + `--text` 字；150ms 过渡
- **成对字段**：间隔(64) + 单位(72) 一行；开始/结束两个小标签 + time input(96) 一行
- **子配置层级**：2px accent 左竖线 + padding-left 12，与主表单区分
- **头部**：标题 15/600 + ✕ 关闭；**底部操作栏**：sticky、1px 上边框、高 44、取消 ghost 左 / 保存 primary 右

## 落地约束（不变）

- token 化、动效 100–200ms ease-out 仅 hover/switch/弹层
- 交互行为契约不因重设计改变：Tab 独立 pane + 表单挂起守卫、[hidden] 根治规则、
  store-changed / popup-replace / popup_action 事件链路
